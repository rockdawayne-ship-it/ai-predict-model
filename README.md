# 중대안전 지능형 CCTV 알고리즘

이 저장소는 산업 현장의 중대안전 사고를 예방하기 위한 지능형 CCTV 알고리즘의 **참조 구현**을 제공합니다.
카메라 영상에서 위험 상황을 탐지하고, 위험 점수를 계산해 경보를 발생시키는 과정을 모듈화했습니다.

## 주요 기능
- **침입/위험구역 진입 탐지**: 지정된 다각형 영역에 사람 객체가 진입하면 경보
- **PPE(안전 보호구) 착용 확인**: 헬멧, 조끼 등 착용 여부 추정
- **넘어짐/추락 징후 탐지**: 사람의 자세/속도 기반 낙상 위험 평가
- **연기/화재 징후 탐지(선택)**: 시각적 특징 기반 간단 점수화
- **위험 점수 집계**: 이벤트별 가중치로 종합 위험도 산정

## 빠른 시작
```bash
python cctv_algorithm.py --video path/to/video.mp4 --zones config/zones.json
```

## 구성
- `cctv_algorithm.py`: 전체 파이프라인과 위험 점수 계산 로직
- `config/`: 위험구역 정의, 가중치, 임계값 등을 보관하는 위치(예시)

## 주의
이 코드는 **데모/참고용**이며 실제 운영 환경에서는 모델 성능 검증, 데이터 보호, 윤리/법적 기준
준수가 필요합니다.
